Question-2: What is the difference between innerHTML, innerText, and textContent?

Answer:
1. innerHTML get or set the HTML content inside an element,
2. innerText get or set the text content inside a HTML element.
3. textContent gets or sets the raw text inside an element and hidden elements.

Question-3: What is event delegation in the DOM?

Answer: Event delegation is a technique where the event listener is attached to a parent element innstead of its child elements. Here, event bubbling is used to handling the event efficiently.

Question-4: What is event bubbling in the DOM?

Answer: Event bubbling is a process where an event starts at the target element and then propagates (bubbles up) to its ancestors in the DOM hierarchy.
