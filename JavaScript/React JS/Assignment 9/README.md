# App Store

## Project Name: App Store

### Purpose:
The "App Store" project is a web-based application designed to help users explore and discover various services, trends, productivity tools, healthcare information, and educational resources. The platform provides a user-friendly interface with dynamic features like theme switching, sign-in functionality, and easy navigation.

---

## Live URL:
[App Store - Live Demo](https://app-store-9a537.web.app/)  

---

## Key Features:
- **User Authentication**: Allows users to sign in, manage their profiles, and sign out.
- **Responsive Design**: Fully responsive layout, optimized for mobile, tablet, and desktop devices.
- **Theme Switching**: Option to switch between two themes (Acid and Sunset) for better user customization.
- **Easy Navigation**: Links to different services and categories like Trends, Healthcare, Productivity, Education, and FAQ.
- **Dynamic UI**: Login and Profile sections appear conditionally based on user authentication status.
- **Social Media Integration**: Links to the project's official social media platforms like Twitter, YouTube, and Facebook.

---

## NPM Packages Used:
- **React**: A JavaScript library for building user interfaces.
- **React Router**: To handle navigation and routing within the app.
- **SweetAlert**: For displaying customizable pop-up alerts for actions like successful sign-outs.
- **Tailwind CSS**: Utility-first CSS framework for designing responsive layouts and components.
- **React Context API**: For state management related to authentication and theme switching.
- **React Icons**: For adding custom icons like the moon and sun for theme toggling.
- **react-hook-form**: For handling form submissions and validations efficiently (if used).
